VizPilot

VizPilot: Automated Onboarding for SVG-based Composite Visualizations
using Multimodal LLMs

Composite visualizations are expressive and powerful — but they impose a high cognitive load on first-time users. Existing onboarding tools are platform-dependent, require manual effort, and break down when faced with structurally complex multi-view designs.

VizPilot takes a different approach: it reverse-engineers composite visualization structure directly from raw SVG artifacts. A two-stage Composite Visualization Analyzer powered by Multimodal LLMs decomposes each visualization into individual components, extracts structured semantic knowledge, and anchors explanations to precise SVG elements via hierarchical DOM traversal — all automatically, with no authoring required.

The resulting onboarding interface supports Narrative Scrollytelling — guided, step-by-step walkthroughs with synchronized highlighting — and Free Exploration for user-driven inquiry. Deployed as a browser extension, VizPilot works across any SVG-based composite visualization.

Install Viewer

  1. Download and unzip the file
  2. Go to chrome://extensions
  3. Enable "Developer mode" (top right)
  4. Click "Load unpacked"
  5. Select the unzipped folder
  6. Open any visualization in the gallery

This extension replays pre-generated VizPilot onboarding tours. It does not include the automated authoring pipeline — see the Demo tab to learn how tours are created.
